<product_requirements>
The user needs to enhance a liquor store dashboard app for tracking stock and sales. The existing app manages core liquor sales, stock entry (date-wise), basic brand management (top brands, overstocked, sales trends), and demand forecasting based on sales data (uploaded via Excel). It's deployed on Vercel (frontend) and Render (backend) with GitHub auto-deployment.

3.  **Comprehensive Upload and Update History:** Expand history log for uploads, edits, stock resets, displayed via an Upload History button, retained for 60 days.
4.  **Stock Data Reset With Safety Checks:** Feature to erase date-wise stock after confirming Excel exports. Automatic backup on each reset, downloadable as Excel.
5.  **Safer Deployment Workflow:** Use feature branches in GitHub to prevent auto-deployment until features are ready.
